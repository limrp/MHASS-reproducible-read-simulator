# MHASS

**Microbiome HiFi Amplicon Sequencing Simulator**:  
[Preprint](https://arxiv.org/abs/2509.12428)  |  [Publication in _Bioinformatics_](https://doi.org/10.1093/bioinformatics/btaf656)

A complete pipeline for simulating PacBio HiFi amplicon sequencing data for microbiome studies.

## About this fork

This repository is a research-oriented fork of
[MHASS](https://github.com/rhowardstone/MHASS), the Microbiome HiFi Amplicon
Sequencing Simulator.

The original MHASS project provides the simulation framework on which this
repository is based. This fork is being developed for a thesis project focused
on benchmarking bioinformatics analysis workflows using simulated PacBio HiFi
amplicon data.

Benchmarking introduces additional experimental-control requirements. The
pipelines being compared should be evaluated against the same known synthetic
community, and an exact simulation should be reproducible when its inputs,
parameters, master seed, software versions, and simulation resources are held
constant. Distinct master seeds can then be used to generate independent
stochastic sequencing replicates from the same fixed ground truth.

The changes in this fork are therefore intended as project-specific extensions
for controlled benchmarking rather than corrections to the upstream MHASS
methodology.

The reproducibility-oriented extensions currently include:

- `--counts-file`, which allows a predefined ASV × sample count matrix to be
  used as the intended community composition instead of generating a new
  abundance matrix with metaSPARSim.
- `--seed`, which provides deterministic control of downstream stochastic
  simulation, including `np` sampling, per-template PBSIM seeds, and final
  read-orientation randomization.
- Regression tests and GitHub Actions CI for the reproducibility-related
  behavior introduced in this fork.

For reproducible benchmarking, `--counts-file` and `--seed` are intended to be
used together. Native metaSPARSim abundance generation remains available; this
fork does not claim deterministic native metaSPARSim abundance generation.

The original MHASS authors, publication, and citation remain the scientific
foundation of this work, and users of this fork should also cite the original
MHASS publication.

## Installation

For installation of the original MHASS project, please refer to the [upstream repository](https://github.com/rhowardstone/MHASS).

To install this reproducibility-oriented fork:

```bash
git clone https://github.com/limrp/MHASS-reproducible-read-simulator.git
cd MHASS-reproducible-read-simulator
bash install_dependencies.sh
```
After installation:

```bash
conda activate mhass
```
Note: Installation requires conda, samtools

## Usage

Note: For generating the ASV FASTA file required for MHASS (`amplicons.fa`, below) from a collection of genomes, you may use [AmpliconHunter](https://github.com/rhowardstone/AmpliconHunter), developed by the original MHASS authors.

For an example of using AmpliconHunter together with MHASS, please refer to the [original MHASS evaluation repository](https://github.com/rhowardstone/MHASS_evaluation).

### Simple test

```bash
mhass --amplicon-fasta Test-data_ATCC_16S_MSA-1003/amplicons.fa \
        --amplicon-genome-labels Test-data_ATCC_16S_MSA-1003/amplicon_labels.txt \
        --barcode-file Test-data_ATCC_16S_MSA-1003/barcodes.tsv --np-distribution-type lognormal \
        --output-dir testout 
```
This will produce a directory at `./testout`, containing the output of the simulation: 

* `counts.tsv`: ASV counts per sample, either generated by metaSPARSim or obtained from the supplied external count matrix.
* `counts_meta.tsv`: Sample library sizes
* `sample_barcode_map.tsv`: Mapping of samples to barcodes
* `sequence_file_mapping.tsv`: Detailed template mappings
* `combined_reads.fastq`: Final output FASTQ file


### Basic Command

```bash
mhass --amplicon-fasta amplicons.fa --amplicon-genome-labels labels.tsv --output-dir output/
```

### Reproducible benchmarking with fixed counts

For controlled benchmarking, an externally defined ASV × sample count matrix
can be supplied together with a master seed:

```bash
mhass \
    --amplicon-fasta amplicons.fa \
    --counts-file fixed_counts.tsv \
    --seed 12345 \
    --output-dir output/
```

When `--counts-file` is supplied, MHASS skips metaSPARSim abundance generation
and uses the supplied count matrix as the intended community composition.
`--amplicon-genome-labels` is therefore not required in this mode.

The master seed deterministically controls downstream stochastic simulation,
including `np` sampling, per-template PBSIM seeding, and final read
orientation.

Re-running the same fixed inputs and parameters with the same master seed is
intended to reproduce the same downstream simulation. Different master seeds
can be used to generate independent stochastic sequencing replicates from the
same fixed ground-truth community.

## Parameters

### Required Parameters

* `--amplicon-fasta`: Input FASTA file of amplicon reference sequences.
* `--output-dir`: Path to the directory where all output files will be written.

### Conditionally Required Parameters

* `--amplicon-genome-labels`: TSV file mapping each ASV to a genome ID. Format: `asvid<TAB>genomeid`. Required when `--counts-file` is not supplied. It is not required when an external count matrix is used.

### Optional Parameters

#### Reproducibility and external counts

* `--counts-file`: Precomputed ASV × sample count matrix in TSV format. When supplied, metaSPARSim count generation is skipped and these counts are used as the intended community composition.
* `--seed`: Non-negative master seed for deterministic downstream simulation, including `np` sampling, per-template PBSIM simulation, and final read orientation. For reproducible benchmarking, use together with `--counts-file`.

#### Native count-simulation parameters

The following parameters control metaSPARSim count generation and are used only when `--counts-file` is not supplied:

* `--num-samples`: Number of synthetic samples to generate (default: `10`).
* `--num-reads`: Number of reads per sample (default: `10000`).
* `--var-intercept`: Intercept of the abundance variability model across samples (default: `1.47565981333483`).
* `--var-slope`: Slope of the abundance variability model as a function of ASV abundance (default: `-0.909890963463704`).
* `--genome-distribution`: Relative genome abundance distribution model. Options: `uniform`, `lognormal`, `powerlaw`, or `empirical:<file.tsv>` (default: `uniform`).

When `--counts-file` is supplied, the external matrix defines the sample count and library composition, and these metaSPARSim parameters do not override it.

#### Sequencing and template parameters

* `--barcode-file`: Optional TSV file of barcodes with columns: `id`, `forward`, `reverse`.
* `--subread-accuracy`: Mean subread accuracy used for PBSIM3 simulation (default: `0.65`).
* `--difference-ratio`: Difference (error) ratio for PBSIM in format `substitution:insertion:deletion`. Each value must be 0-1000. Default `6:55:39` is for PacBio RS II. Use `22:45:33` for PacBio Sequel, `39:24:36` for ONT (default: `6:55:39`).
* `--np-distribution-type`: Distribution type for number of passes. Options: `empirical` or `lognormal` (default: `empirical`).
* `--lognormal-mu`: `mu` parameter for lognormal number-of-passes distribution (default: `3.88`).
* `--lognormal-sigma`: `sigma` parameter for lognormal number-of-passes distribution (default: `1.22`).
* `--np-min`: Minimum number of passes for lognormal distribution (default: `2`).
* `--np-max`: Maximum number of passes for lognormal distribution (default: `59`).
* `--np-distribution`: Optional TSV file specifying an empirical number-of-passes distribution. When omitted, MHASS uses its bundled default empirical distribution.
* `--threads`: Number of parallel threads to use for simulation. By default, MHASS uses the number of CPUs reported by the current system.

## Input File Formats

### 1. Amplicon FASTA

```
>ASV001
ATCGATCGATCGATCG...
```

### 2. Amplicon-to-Genome Label TSV

```
asvid	genomeid
ASV001	Genome1
ASV002	Genome2
```

### 3. Barcode File (optional)

```
BarcodeID	ForwardBarcode	ReverseBarcode
BC01	CACATATCAGAGTGCG	TGGCGTGCATGATTCGA
```

### 4. Num-Passes Distribution (optional)

```
num_passes	count
2	19
3	23159
...
```

### 5. Empirical Genome Abundance (if used)

```
genomeid	proportion
Genome1	0.45
Genome2	0.30
```

### 6. External Count Matrix (optional)

Used with `--counts-file` to define the intended ASV × sample composition
directly.

```text
ASVID    Sample1    Sample2    Sample3
ASV001   100        50         200
ASV002   20         150        75
ASV003   80         0          25
```

The first column must be named ASVID and contain identifiers matching the
complete FASTA headers in `--amplicon-fasta` (without the leading `>`). Each
remaining column represents one sample and must have a unique, non-empty name.

Counts must be non-negative integers. Every ASV present in the amplicon FASTA
must also be represented in the count matrix; use a count of `0` when an ASV is
intentionally absent from a sample.

## Workflow

1. **Count Definition**:
   * Native mode: uses `metaSPARSim` to simulate ASV abundance across samples.
   * Fixed-count mode: when `--counts-file` is supplied, uses the external
     ASV × sample matrix directly and skips metaSPARSim count generation.
2. **Template Creation**: Templates are created from each ASV × sample combination using the assigned barcode and sampled `np` values.
3. **Read Simulation**: PBSIM3 simulates PacBio subreads per template with user-defined `--subread-accuracy`.
4. **CCS Processing**: Subreads are collapsed into CCS reads using `ccs`.
5. **Read Relabeling**: All CCS reads are relabeled and merged into `combined_reads.fastq`.
6. **Cleanup**: Intermediate files are cleaned up, leaving only final outputs.

## Examples

```bash
mhass --amplicon-fasta test/amplicons.fa \
      --amplicon-genome-labels test/labels.tsv \
      --output-dir output/ \
      --num-samples 5 \
      --num-reads 1000 \
      --threads 4 \
      --subread-accuracy 0.9
```


### Example for PacBio Sequel
```bash
mhass --amplicon-fasta test/amplicons.fa \
      --amplicon-genome-labels test/labels.tsv \
      --output-dir output_sequel/ \
      --num-samples 5 \
      --num-reads 1000 \
      --difference-ratio 22:45:33 \
      --threads 4
```

### Example for Oxford Nanopore
```bash
mhass --amplicon-fasta test/amplicons.fa \
      --amplicon-genome-labels test/labels.tsv \
      --output-dir output_ont/ \
      --num-samples 5 \
      --num-reads 1000 \
      --difference-ratio 39:24:36 \
      --threads 4
```

### Reproducible fixed-count simulation

```bash
mhass \
    --amplicon-fasta amplicons.fa \
    --counts-file fixed_counts.tsv \
    --seed 12345 \
    --output-dir reproducible_simulation/ \
    --threads 4
```
